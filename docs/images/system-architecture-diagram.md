## 📊 데이터 흐름도

### 1️⃣ 시장 데이터 흐름 (Market Data Flow)

```
Binance WebSocket ──▶ binance-market-full ──▶ NATS (market.data.*) ──▶ Dashboard Backend
         │                                                                    │
         └─ @ticker, @trade                                                   ▼
                                                                     WebSocket Broadcast
                                                                              │
                                                                              ▼
                                                                     React Frontend (실시간 UI)
```

### 2️⃣ 잔고 데이터 흐름 (Balance Flow)

```
                ┌──────────────┐
                │    Vault     │
                │  (API Keys)  │
                └──────┬───────┘
                       │
                       ▼
Binance REST API ◀── binance-spot-balance ──▶ NATS (balance.spot.all)
                                                        │
                                            ┌───────────┴───────────┐
                                            ▼                       ▼
                                     Dashboard Backend       Risk Engine
```

### 3️⃣ 주문 처리 흐름 (Order Flow)

```
Client Request ──▶ gRPC Server ──▶ Risk Manager ──▶ Order Router ──▶ Binance API
      │               :50051              │                │             │
      │                                   ▼                │             │
      │                           Position Check           │             ▼
      │                           Leverage Check           │      Order Response
      │                                                    │             │
      │                                                    ▼             │
      │                                            Exchange Connector    │
      │                                              (WebSocket)         │
      │                                                    │             │
      │                                                    ▼             │
      │                                            NATS Publish:         │
      │                                            orders.create.*       │
      │                                            orders.update.*       │
      │                                            orders.filled.*       │
      │                                                    │             │
      │                                            ┌───────┴───────┐     │
      │                                            ▼               ▼     │
      │                                     Dashboard        Position    │
      │                                     Backend          Manager     │
      ◀────────────────────────────────────────────────────────────────────
```

## 🚀 시스템 시작 순서

```
make start-all
       │
       ├─── 1. Infrastructure ─────────────────────────────────────────────────────────
       │         │
       │         ├── docker-compose up -d nats    (NATS JetStream 시작)
       │         ├── docker-compose up -d redis   (Redis 캐시 시작)
       │         └── docker-compose up -d vault   (Vault 시작 + 자동 언씰)
       │
       ├─── 2. Vault 초기화 (최초 1회) ────────────────────────────────────────────────
       │         │
       │         ├── ./scripts/init-vault.sh      (언씰 키 생성)
       │         └── ./scripts/store-binance-keys.sh (API 키 저장)
       │
       ├─── 3. Services 시작 ──────────────────────────────────────────────────────────
       │         │
       │         ├── go run cmd/binance-market-full/main.go   (시세 수집)
       │         ├── go run cmd/binance-spot-balance/main.go  (잔고 조회)
       │         └── go run cmd/binance-futures-position/main.go (선물 포지션)
       │
       └─── 4. Dashboard 시작 ─────────────────────────────────────────────────────────
                 │
                 ├── ./dashboard/oms-dashboard-real           (Backend :8080)
                 └── cd dashboard/frontend && npm start       (Frontend :3000)
```
