# mExOms User Guides

Comprehensive guides for different user roles in the Multi-Exchange Order Management System.

## User Roles

### 🎯 [Traders](./trader-guide.md)
- **Who**: Active traders using mExOms for manual and automated trading
- **Focus**: Order placement, position monitoring, risk management
- **Tools**: Web interface, trading bots, mobile apps
- **Key Features**: Multi-exchange trading, real-time data, portfolio analytics

### 👨‍💼 [Administrators](./admin-guide.md)
- **Who**: System administrators managing mExOms infrastructure
- **Focus**: System deployment, monitoring, user management, security
- **Tools**: Admin dashboard, CLI tools, monitoring systems
- **Key Features**: User permissions, system health, performance optimization

### 👨‍💻 [Developers](./developer-guide.md)
- **Who**: Developers building applications on top of mExOms
- **Focus**: API integration, SDK usage, custom strategies
- **Tools**: gRPC/REST APIs, SDKs, development frameworks
- **Key Features**: API documentation, code examples, testing tools

### 🏢 [Institutional Users](./institutional-guide.md)
- **Who**: Hedge funds, trading firms, market makers
- **Focus**: High-volume trading, compliance, risk management
- **Tools**: Institutional APIs, reporting tools, compliance dashboards
- **Key Features**: Multi-account management, regulatory compliance, advanced analytics
